# LiberClean v0.3.0

发布日期：2026-10-23

相较 v0.2.0，本次主要改进小窗口布局、维护操作和结果反馈。

- **界面更简洁**：采用更接近 macOS 的灰白风格，精简重复说明和提示。
- **窗口与列表适配**：统一插件打开高度，减少底部留白；优化列表滚动、表头和底部操作栏，提升小窗口下的可用性。
- **项目清理可指定目录**：支持选择项目或上级目录，也可输入路径；执行前复核已检查的目录范围。
- **应用卸载兼容改进**：适配新版 Mole 的检查与确认交互，修复检查等待过久或超时的问题。
- **执行结果更清楚**：系统优化逐项显示实际状态和原因，需处理项置顶并支持筛选；修复无安装包时误报失败，真实错误直接显示目录、退出码和日志入口。

升级后请结束插件进程并重新打开，以加载新版界面和本地脚本。

验证：61 项测试通过，TypeScript 检查和插件构建通过；已在本机 Mole 1.62.0 上核验安装包与系统优化的只读检查。
