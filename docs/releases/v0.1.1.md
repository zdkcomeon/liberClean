# LiberClean v0.1.1

发布日期：2026-10-21

本次更新带来全新的 LiberClean 品牌图标，统一插件入口与页面内的图标显示。

## 更新内容

- **全新 logo**：采用深蓝底色、LC 字母与青色星芒，主图标为 256×256 PNG，适合 uTools 插件入口和小窗口显示。
- **图标显示统一**：同步更新侧栏、运行环境提示页和 64×64 favicon。
- **项目展示完善**：README 增加新 logo 展示，并保存图标的生成说明，方便后续维护。
- **版本信息同步**：插件配置、项目包信息、构建产物和启动日志统一更新为 `0.1.1`。

## 当前版本包含的功能

- 查看系统状态、CPU、内存、网络与存储空间，分析目录和磁盘占用。
- 通过图形界面完成深度清理、应用卸载、系统优化、项目清理和安装包清理。
- 先检查维护范围，再根据页面提示勾选、核对和确认操作。
- 打开插件时自动检测 Mole 安装状态，提供安装说明和手动选择路径入口。
- 在环境设置中更新 Mole 并查看进度与结果，在操作记录页面查看本机维护记录。

## 使用与升级

LiberClean 运行于 macOS 的 uTools 中，需要本机安装 Mole CLI。图形维护流程已在 Mole `1.61.0` 验证。

更新插件后，请结束插件进程并重新打开，以加载新的图标和界面资源。从源码使用时，先执行 `pnpm build`，再加载或打包生成的 `dist/` 目录。安装与开发步骤见 [README](../../README.md)。

清理操作可能永久删除文件，执行前请核对页面列出的处理范围。
