# LiberClean v0.2.0

发布日期：2026-10-22

本次更新重新整理插件小窗口的导航和维护操作，采用蓝白配色与深色文字，提升页面可读性，并完善应用图标、长列表浏览和功能文档。

## 更新内容

- **顶部导航**：7 个主要功能横向排列，操作记录和环境设置位于右上角，内容区使用完整窗口宽度；窄窗口支持横向滚动，保留 `⌘ / Ctrl + 1` 到 `9` 的页面切换快捷键。
- **紧凑概览**：默认内容高度调整为 560 像素，移除与导航重复的维护卡片，将更多硬件信息收进设备卡片按需展开。
- **更方便的检查入口**：深度清理、系统优化、项目清理和安装包清理首次进入时，开始检查按钮居中显示；已有任务后，顶部提供重新检查入口。
- **清晰的配色**：统一按钮、列表、图表、任务状态和确认弹窗的蓝白配色，加深正文、说明及禁用按钮文字；任务步骤采用深灰文字和蓝色图标。
- **应用图标与长列表**：在 uTools 中按需读取并缓存原生应用图标，读取失败时显示通用图标；超过 100 项的应用列表使用虚拟列表，支持键盘选择。
- **状态展示完善**：异常数值显示为暂不可用，部分扫描结果提供明确提示，并保留焦点提示和减少动态效果的支持。
- **文档与下载**：README 新增 6 张功能截图、检查入口说明和构建目录安装步骤；Release 提供已构建的插件目录 ZIP。

## 安装与升级

1. 下载本次 Release 的 `LiberClean-v0.2.0-dist.zip` 并解压，在 uTools 开发者工具中导入 `dist/plugin.json`。
2. 确认本机已安装 Mole CLI；未检测到可用命令时，按环境设置中的说明安装或手动选择路径。
3. 升级后结束插件进程并重新打开，以加载新版界面和本地脚本。

ZIP 附件包含已构建的插件目录；需要 `.upx` 时，通过 uTools 开发者工具对 `dist/` 打包。从源码构建和日常操作见 [README](https://github.com/zdkcomeon/liberClean/blob/v0.2.0/README.md)。

清理操作可能永久删除文件，执行前请核对页面列出的处理范围。图形维护适配已在 Mole `1.61.0` 验证，其他版本以运行时兼容性检查为准。
